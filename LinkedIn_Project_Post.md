## Suggested LinkedIn Post

📊 **New Project: E-commerce Sales & Profit Analysis**

As a BCA graduate building my Data Analyst portfolio, I wanted a project that went beyond a clean sample dataset — so I worked with 7,500 order records that had realistic data-quality issues baked in: inconsistent text casing, missing values, extra whitespace.

Here's what the project covered:

🧹 **Data Cleaning** — Standardized 700+ inconsistent text values, resolved missing fields using logical derivation (never invented data), and documented every decision in a cleaning log.

📈 **Excel Analysis** — Built a 12-sheet workbook with live SUMIFS-based KPI tables (no hardcoded numbers) covering category, region, monthly, customer, and product performance.

🗃️ **SQL Queries** — Wrote 20 queries spanning aggregation, CASE logic, HAVING filters, and window functions (month-over-month growth) to answer real business questions.

📊 **Power BI Dashboard Spec** — Designed a full dashboard with DAX measures, KPI cards, and interactive slicers.

**Key finding that surprised me:** the category with the *most sales* (Electronics, ₹6.21 Cr) was the *least profitable* (12.0% margin) — while a smaller category (Fashion) ran at a 50.2% margin. All 88 loss-making orders in the dataset traced back to over-discounted Electronics. It's a good reminder that sales volume and profit aren't the same story.

Full write-up, SQL file, and dashboard guide are on my GitHub — link in comments 👇
